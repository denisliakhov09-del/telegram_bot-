# Winner's Circle — Telegram Bot Demo

Готовый локальный тестовый проект на Python + aiogram 3.

## Что проверяет
- /start
- прием числового ID
- первый сценарий
- смену сообщений с задержкой
- SQLite-хранилище
- повторную отправку ID
- demo-экран после повторной проверки
- inline-кнопки
- внешнюю ссылку из `.env`

## Важно
Эта версия НЕ подключается к 1win API и НЕ умеет определять реальный депозит. Повторная «верификация» — только DEMO-сценарий для проверки UX/технической работы. Не выдавай demo-результат за реальное подтверждение депозита.

## Windows
1. Установи Python 3.10+.
2. Создай бота через BotFather и получи токен.
3. Скопируй `.env.example` в `.env`.
4. В `.env` вставь BOT_TOKEN и при необходимости REF_LINK/PROMO_CODE.
5. Двойной клик по `run_windows.bat`.

Если `python` не работает, используй в CMD:
`py -m pip install -r requirements.txt`
`py bot.py`

После запуска открой бота, отправь `/start`, затем числовой ID, например `123456789`. Отправь его повторно для проверки второго сценария.
